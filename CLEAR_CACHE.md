# Инструкция по очистке кеша для обновления изображений

## Проблема
После замены изображений 8.jpg и 9.jpg некоторые браузеры продолжают показывать старые версии из-за кеширования.

## Решение 1: Обновить конфигурацию Nginx (рекомендуется)

1. Обновите конфигурацию nginx на сервере:

```bash
# Скопируйте обновленную конфигурацию
sudo cp /root/sfera-deti/nginx.conf.example /etc/nginx/sites-available/sfera-deti

# Проверьте конфигурацию
sudo nginx -t

# Перезагрузите nginx
sudo systemctl reload nginx
```

2. Пересоберите проект с новыми изображениями:

```bash
cd /root/sfera-deti
npm run build
```

## Решение 2: Очистка кеша на сервере

Если nginx использует кеш (если настроен), очистите его:

```bash
# Если используется nginx cache, найдите директорию кеша и очистите
# Обычно это /var/cache/nginx/
sudo rm -rf /var/cache/nginx/*
sudo systemctl reload nginx
```

## Решение 3: Принудительное обновление для пользователей

Пользователи могут принудительно обновить кеш:

### На компьютере:
- **Chrome/Edge**: Ctrl+Shift+R (Windows) или Cmd+Shift+R (Mac)
- **Firefox**: Ctrl+F5 (Windows) или Cmd+Shift+R (Mac)
- **Safari**: Cmd+Option+R (Mac)

### На iPhone/iPad (Safari):

**Способ 1: Принудительная перезагрузка страницы**
1. Откройте Safari
2. Нажмите и удерживайте кнопку обновления (круговая стрелка) в адресной строке
3. Выберите "Перезагрузить без содержимого кэша"

**Способ 2: Очистка кэша Safari через настройки**
1. Откройте **Настройки** на iPhone
2. Прокрутите вниз и выберите **Safari**
3. Прокрутите вниз и нажмите **Очистить историю и данные веб-сайтов**
4. Подтвердите действие, нажав **Очистить историю и данные**

**Способ 3: Очистка данных конкретного сайта**
1. Откройте Safari
2. Нажмите на кнопку **aA** (в адресной строке слева)
3. Выберите **Настройки веб-сайта**
4. Прокрутите вниз и нажмите **Удалить данные веб-сайта**
5. Подтвердите удаление

**Способ 4: Закрыть и переоткрыть вкладку**
1. Закройте вкладку с сайтом (смахните вверх)
2. Откройте новую вкладку
3. Введите адрес сайта заново

**Способ 5: Режим инкогнито (приватный режим)**
1. Откройте Safari
2. Нажмите на кнопку вкладок (квадратики в правом нижнем углу)
3. Нажмите "Приватный" внизу
4. Откройте сайт в приватной вкладке (кеш не используется)

Или очистить кеш браузера в настройках.

## Решение 4: Временное отключение кеширования для изображений

Если нужно срочно обновить изображения, временно измените конфигурацию:

```nginx
# Временно отключить кеширование изображений
location ~* \.(jpg|jpeg|png|gif|webp)$ {
    expires -1;
    add_header Cache-Control "no-cache, no-store, must-revalidate";
    add_header Pragma "no-cache";
}
```

После применения изменений перезагрузите nginx:
```bash
sudo systemctl reload nginx
```

**Важно**: После того как все пользователи увидят новые изображения, верните нормальное кеширование для производительности.

## Проверка

После применения изменений проверьте:

```bash
# Проверьте заголовки ответа
curl -I https://sfera-deti.ru/8.jpg
curl -I https://sfera-deti.ru/9.jpg

# Должны увидеть заголовки:
# Cache-Control: public, must-revalidate
# ETag: "..."
```

## Долгосрочное решение

Для будущих обновлений изображений рекомендуется:

1. Использовать версионирование файлов (например, `8-v2.jpg`)
2. Или использовать query string с версией (например, `8.jpg?v=2`)
3. Или использовать хеш имени файла при сборке (Vite делает это автоматически для файлов в `src/`)
