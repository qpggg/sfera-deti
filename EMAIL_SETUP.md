# Настройка отправки заявок на email через EmailJS

## Что такое EmailJS?

EmailJS - это сервис, который позволяет отправлять email прямо с фронтенда без бекенда. Бесплатный тариф позволяет отправлять до 200 писем в месяц.

## Шаг 1: Регистрация на EmailJS

1. Перейдите на сайт [EmailJS](https://www.emailjs.com/)
2. Нажмите "Sign Up" и зарегистрируйтесь (можно через Google/GitHub)
3. Подтвердите email (если требуется)

## Шаг 2: Подключение Email сервиса

1. Войдите в личный кабинет EmailJS
2. Перейдите в раздел **"Email Services"**
3. Нажмите **"Add New Service"**
4. Выберите ваш email провайдер:
   - **Gmail** (если используете Gmail)
   - **Outlook** (если используете Outlook)
   - **Yahoo** (если используете Yahoo)
   - **Custom SMTP** (для любого другого email)
5. Следуйте инструкциям для подключения:
   - Для Gmail: нужно будет авторизоваться через Google
   - Для Custom SMTP: введите настройки SMTP вашего почтового сервера
6. После подключения вы получите **Service ID** (например: `service_abc123`)
7. Сохраните этот Service ID

## Шаг 3: Создание Email шаблона

1. Перейдите в раздел **"Email Templates"**
2. Нажмите **"Create New Template"**
3. Заполните шаблон:

**Subject (Тема письма):**
```
Новая заявка с сайта СФЕРА
```

**Content (Содержание письма):**
```
🎯 Новая заявка с сайта СФЕРА

👤 Родитель: {{parent_full_name}}
👶 Ребёнок: {{child_full_name}}
🎂 Возраст: {{child_age}} лет
📞 Телефон: {{phone}}
🏫 Сад/Школа: {{source}}
💬 Комментарий: {{comment}}

⏰ Дата: {{date}}
```

4. В поле **"To Email"** укажите ваш email (куда будут приходить заявки)
5. В поле **"From Name"** укажите имя отправителя (например: "Сайт СФЕРА")
6. Нажмите **"Save"**
7. Сохраните **Template ID** (например: `template_xyz789`)

## Шаг 4: Получение Public Key

1. Перейдите в раздел **"Account"** → **"General"**
2. Найдите **"Public Key"** (например: `abcdefghijklmnop`)
3. Сохраните этот ключ

## Шаг 5: Настройка переменных окружения

### Для разработки (локально)

Создайте файл `.env` в корне проекта:

```env
VITE_EMAILJS_SERVICE_ID=service_abc123
VITE_EMAILJS_TEMPLATE_ID=template_xyz789
VITE_EMAILJS_PUBLIC_KEY=abcdefghijklmnop
```

**Важно**: 
- Не коммитьте файл `.env` в git (он уже должен быть в `.gitignore`)
- Замените значения на ваши реальные ID и ключи

### Для продакшена (на сервере)

#### Вариант 1: Переменные окружения при сборке

```bash
export VITE_EMAILJS_SERVICE_ID="service_abc123"
export VITE_EMAILJS_TEMPLATE_ID="template_xyz789"
export VITE_EMAILJS_PUBLIC_KEY="abcdefghijklmnop"
npm run build
```

#### Вариант 2: Создать .env файл на сервере

```bash
cd /root/sfera-deti
nano .env
```

Добавьте:
```env
VITE_EMAILJS_SERVICE_ID=service_abc123
VITE_EMAILJS_TEMPLATE_ID=template_xyz789
VITE_EMAILJS_PUBLIC_KEY=abcdefghijklmnop
```

Затем пересоберите:
```bash
npm run build
```

## Шаг 6: Проверка работы

1. Запустите проект локально: `npm run dev`
2. Заполните форму заявки на сайте
3. Отправьте форму
4. Проверьте ваш email - должно прийти письмо с данными заявки

## Тарифы EmailJS

- **Free**: 200 писем/месяц
- **Paid**: от $15/месяц (10,000+ писем)

Для большинства сайтов бесплатного тарифа достаточно.

## Решение проблем

### Письма не приходят

1. **Проверьте настройки Email сервиса**
   - Убедитесь, что сервис подключен правильно
   - Для Gmail может потребоваться разрешение "менее безопасных приложений" или создание пароля приложения

2. **Проверьте переменные окружения**
   - Убедитесь, что все три переменные установлены
   - Проверьте правильность ID и ключей

3. **Проверьте шаблон**
   - Убедитесь, что в шаблоне используются правильные переменные: `{{parent_full_name}}`, `{{phone}}` и т.д.
   - Проверьте, что указан правильный email получателя

4. **Проверьте консоль браузера**
   - Откройте DevTools (F12)
   - Посмотрите на ошибки в консоли
   - Проверьте вкладку Network на наличие ошибок

### Ошибка "Service not found"

- Проверьте правильность `VITE_EMAILJS_SERVICE_ID`
- Убедитесь, что сервис подключен в личном кабинете EmailJS

### Ошибка "Template not found"

- Проверьте правильность `VITE_EMAILJS_TEMPLATE_ID`
- Убедитесь, что шаблон создан и сохранен

### Ошибка "Invalid public key"

- Проверьте правильность `VITE_EMAILJS_PUBLIC_KEY`
- Убедитесь, что используете Public Key, а не Private Key

## Безопасность

⚠️ **Важно**: При использовании Vite переменные окружения с префиксом `VITE_` попадают в клиентский код. Это означает, что Service ID, Template ID и Public Key будут видны всем, кто откроет исходный код страницы.

Это нормально для EmailJS, так как:
- Public Key предназначен для использования на клиенте
- Service ID и Template ID не дают доступа к вашему аккаунту
- EmailJS имеет встроеную защиту от спама

Но для дополнительной безопасности можно:
- Ограничить количество писем в настройках EmailJS
- Использовать rate limiting в EmailJS
- Настроить фильтры в вашем email

## Альтернативные решения

Если EmailJS не подходит, можно использовать:
1. **Formspree** - похожий сервис, бесплатно до 50 форм/месяц
2. **Web3Forms** - бесплатный сервис для отправки форм
3. **SendGrid** - более мощный, но требует API ключ
4. **Mailgun** - для больших объемов

Но EmailJS - самый простой и удобный вариант для начала.
