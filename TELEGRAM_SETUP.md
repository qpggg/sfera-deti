# Настройка отправки заявок в Telegram

## Как это работает

При отправке формы заявки автоматически откроется чат в Telegram с пользователем **@skrudj_verif** с предзаполненным текстом заявки. Пользователю нужно будет только нажать кнопку "Отправить" в Telegram.

## Преимущества этого подхода

✅ **Не нужен бот** - не требуется создавать бота через @BotFather  
✅ **Не нужны токены** - не нужно настраивать переменные окружения  
✅ **Простота** - работает сразу, без дополнительной настройки  
✅ **Надежность** - сообщение точно дойдет до получателя  

## Что происходит при отправке формы

1. Пользователь заполняет форму на сайте
2. Нажимает кнопку "Отправить заявку"
3. Автоматически открывается Telegram (в приложении или веб-версии)
4. Открывается чат с @skrudj_verif
5. В поле ввода уже есть готовое сообщение с данными заявки
6. Пользователь нажимает "Отправить" в Telegram

## Формат сообщения

Сообщение в Telegram будет выглядеть так:

```
🎯 Новая заявка с сайта СФЕРА

👤 Родитель: Иванов Иван Иванович
👶 Ребёнок: Иванов Петр Иванович
🎂 Возраст: 5 лет
📞 Телефон: +7 (999) 123-45-67
🏫 Сад/Школа: Детский сад №1
💬 Комментарий: Хотелось бы узнать о гимнастике

⏰ 15.01.2024, 14:30:00
```

## Изменение получателя

Если нужно изменить получателя (сейчас это @skrudj_verif), откройте файл:

`src/utils/telegram.ts`

И измените строку:
```typescript
const TELEGRAM_USERNAME = 'skrudj_verif'
```

На нужный username (без символа @).

## Решение проблем

### Telegram не открывается
- Убедитесь, что у пользователя установлен Telegram или доступна веб-версия
- Проверьте, что браузер не блокирует всплывающие окна

### Чат не открывается с нужным пользователем
- Проверьте правильность username в файле `src/utils/telegram.ts`
- Убедитесь, что username существует в Telegram

### Сообщение не предзаполняется
- Это может быть ограничение браузера или Telegram
- Пользователь может вручную скопировать текст из формы

## Альтернативные решения

Если нужно автоматически отправлять сообщения без участия пользователя, можно:
1. Использовать Telegram Bot API (требует создания бота)
2. Использовать серверный endpoint для отправки
3. Использовать сервисы типа Zapier, Make.com для автоматизации

Но текущее решение самое простое и не требует дополнительной настройки.
