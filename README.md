# СФЕРА — Пространство развития детей

Современный премиальный сайт для детского центра развития СФЕРА.

## Технологии

- **React 19.1.1** — библиотека для UI
- **TypeScript ~5.8.3** — типизированный JavaScript
- **Vite 7.1.2** — сборщик и dev-сервер
- **React Router DOM 7.9.1** — клиентский роутинг
- **Lucide React 0.544.0** — иконки
- **CSS Modules** — модульные стили

## Установка

```bash
npm install
```

## Запуск проекта

```bash
# Разработка
npm run dev

# Сборка для production
npm run build

# Предпросмотр production сборки
npm run preview

# Проверка кода линтером
npm run lint
```

## Структура проекта

```
src/
├── components/     # React компоненты
├── pages/          # Страницы
├── App.tsx         # Главный компонент приложения
├── main.tsx        # Точка входа
└── index.css       # Глобальные стили
```
