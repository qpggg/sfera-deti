# Настройка DNS записей для sfera-deti.ru

## Что нужно настроить в DNS

Для работы сайта на домене `sfera-deti.ru` нужно настроить следующие DNS записи:

### 1. A-запись (основной домен)

**Тип:** `A`  
**Имя/Хост:** `@` или `sfera-deti.ru` (или оставить пустым)  
**Значение/IP:** `IP_АДРЕС_ВАШЕГО_СЕРВЕРА`  
**TTL:** `3600` (или по умолчанию)

Эта запись связывает основной домен с IP адресом вашего сервера.

### 2. A-запись для www поддомена

**Тип:** `A`  
**Имя/Хост:** `www`  
**Значение/IP:** `IP_АДРЕС_ВАШЕГО_СЕРВЕРА` (тот же IP, что и для основной записи)  
**TTL:** `3600` (или по умолчанию)

Эта запись позволяет открывать сайт по адресу `www.sfera-deti.ru`.

## Пример настройки

Если IP адрес вашего сервера, например, `185.123.45.67`, то записи будут такими:

```
Тип: A
Имя: @
Значение: 185.123.45.67
TTL: 3600

Тип: A
Имя: www
Значение: 185.123.45.67
TTL: 3600
```

## Где настраивать DNS

DNS записи настраиваются у вашего регистратора домена или у DNS-провайдера (если используется внешний DNS, например Cloudflare, Яндекс DNS и т.д.).

### Популярные регистраторы:
- **REG.RU** - панель управления → DNS-серверы → Управление DNS-зонами
- **Яндекс.Коннект** - Домены → Управление DNS
- **Timeweb** - Домены → DNS-записи
- **Beget** - Домены → Управление DNS
- **Namecheap** - Domain List → Advanced DNS
- **GoDaddy** - DNS Management

## Как узнать IP адрес сервера

На сервере выполните:
```bash
curl ifconfig.me
```

Или:
```bash
hostname -I
```

## Проверка DNS записей

После настройки DNS записей, проверьте их распространение:

### Windows (PowerShell):
```powershell
nslookup sfera-deti.ru
nslookup www.sfera-deti.ru
```

### Linux/Mac:
```bash
dig sfera-deti.ru
dig www.sfera-deti.ru
```

Или онлайн: https://dnschecker.org/

## Важно!

1. **Распространение DNS** может занять от нескольких минут до 48 часов (обычно 1-4 часа)
2. **Убедитесь**, что на сервере уже настроен nginx и он слушает порт 80 и 443
3. **Перед настройкой SSL** убедитесь, что DNS записи уже распространились (проверьте через nslookup/dig)

## Порядок действий

1. ✅ Узнайте IP адрес вашего сервера
2. ✅ Настройте A-записи в DNS панели регистратора
3. ⏳ Подождите распространения DNS (проверьте через nslookup)
4. ✅ Настройте nginx на сервере
5. ✅ Настройте SSL через certbot

## Дополнительные записи (опционально)

Если используете почту на домене, могут понадобиться MX записи, но для сайта они не обязательны.
